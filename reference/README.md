# Sanitized historical references

These 12 original experiment scripts are preserved as `.py.txt` files for code
and prompt comparison. API key literals and absolute local paths have been
removed. Do not rename and run them as the supported repository entry point.

The supported entry point is `python -m core`. Historical differences and
organization changes are documented in
[`docs/paper_alignment.md`](../docs/paper_alignment.md).
[`source_map.json`](source_map.json) records the selected relative source paths.
