# Synthetic examples

These invented records demonstrate the file schema. They are not extracted from
CAIL-Small or MultiLJP and do not support benchmark or legal conclusions.
The two-entry charge list is only for this toy example.

Charge/article fields are arrays; penalties are final months per record.
The supplied elements have not been audited; run `audit` before CLI embedding.
Real `extract`, `audit`, `embed`, and `predict` commands call the configured APIs. Offline tests use
deterministic fake API responses and tiny vectors instead.
